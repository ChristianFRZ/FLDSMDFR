# MELOXO 01-monolito Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar MELOXO completo (F1 a F7 del PRD, sin F4.7) como un monolito modular que se levanta con `docker compose up --build`.

**Architecture:** Un proceso FastAPI asíncrono con seis módulos de frontera real, cada uno dueño de sus tablas en un solo PostgreSQL, que se hablan solo por `public.py`. Una SPA React se compila a estáticos y FastAPI la sirve. Las tareas periódicas corren en el mismo proceso y son seguras con dos procesos a la vez.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 async, asyncpg, Alembic, httpx, argon2-cffi, PyJWT, mutagen, pytest, locust · React 18, Vite, TypeScript, React Router, TanStack Query, Chart.js, chartjs-chart-matrix, Vitest · PostgreSQL 16, Docker Compose.

**Spec:** `docs/specs/2026-11-05-01-monolito-design.md` (y `docs/prd.md`, fuente de los criterios F1 a F7).

## Global Constraints

- Módulos: `modules/users`, `modules/playlists`, `modules/catalog`, `modules/playback`, `modules/social`, `modules/analytics`.
- Un módulo solo consulta sus tablas. Sin llaves foráneas entre módulos. Solo se importa `app.module_x.public` desde otro módulo.
- `public.py` acepta y devuelve dataclasses o tipos simples, nunca objetos ORM, y no recibe sesión: abre la suya con `session_scope()`.
- El usuario sale siempre del token, nunca del cuerpo de la petición.
- Errores: `{"error": {"code": str, "message": str, "detail": object|null}}`.
- Secretos solo en `.env`. `.env.example` sin valores reales. El `client_id` de Jamendo nunca entra a un archivo versionado.
- Sin recomendaciones, feed, seguidores de personas ni likes públicos.
- Puertos del host: `8080` app, `5433` PostgreSQL. Proyecto Compose: `name: meloxo`. Hay otro proyecto Docker (`fldsmdfr-*`) corriendo en esta máquina: no tocarlo.
- Interfaz en español; código, rutas y nombres en inglés.
- Cada carpeta nueva lleva `README.md` en español: qué contiene y cómo se usa.
- Pruebas de backend contra PostgreSQL real. Jamendo simulado con `respx` en pruebas automáticas.
- Commits pequeños en `01-monolito`, sin `Co-Authored-By`, sin `git push`.

## Review Focus

1. **Token que caduca durante una canción larga:** el audio no se corta; el reproductor renueva el ticket y retoma desde la misma posición (Tareas 5 y 15).
2. **Peticiones `Range` raras:** `bytes=500-`, `bytes=-500`, inicio más allá del final y varios rangos en una cabecera dan respuesta correcta o `416`, sin error 500 (Tarea 5).
3. **Última plaza y enlace agotado a la vez:** dos personas reclaman el último uso de un enlace o el miembro 8; entra solo una, y la otra recibe `409` (Tarea 12).
4. **Pista que desaparece después de estar en listas:** una pista oculta o borrada en un casete, playlist o favoritas se muestra como no disponible y no rompe la vista (Tareas 9, 11, 12 y 17).
5. **Archivo disfrazado:** un `.mp3` que en realidad es texto, una portada que no es imagen o un nombre con `../` se rechazan sin escribir nada fuera de `/media` (Tarea 7).
