# Archivos maestros (SVG)

Son la fuente de verdad del logo. Todo está convertido a trazos, así que no dependen de ninguna fuente instalada.

Cada versión (`symbol`, `horizontal`, `stacked` y `wordmark`) existe con estos sufijos:

| Sufijo | Uso |
| --- | --- |
| Sin sufijo | Tinta `#141317` sobre fondo claro |
| `-color-dark` | Rosa y papel sobre tinta. Es la versión principal |
| `-color-light` | Rosa y tinta sobre papel |
| `-reversed` | Papel sobre tinta, en un solo color. Sus agujeros son 1 unidad más grandes para compensar que lo claro se ve más grueso |
| `-black`, `-white` | Un solo color, exportados. Solo existen para `horizontal` y `stacked`; los del símbolo están en [`docs/brand/web/`](../web/README.md) |
| `-mono-141317` | Tinta en un solo color, exportado. Solo existe para `horizontal`; el del símbolo está en [`docs/brand/web/`](../web/README.md) |

[`meloxo-symbol-small.svg`](meloxo-symbol-small.svg) es un dibujo simplificado para tamaños menores de 32 px.
