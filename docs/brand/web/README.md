# Íconos web

Favicon, íconos de app y manifiesto, generados a partir del símbolo pequeño. La app usa las copias de [`frontend/public/`](../../../frontend/public/README.md).

- [`head-snippet.html`](head-snippet.html): etiquetas listas para pegar en el `<head>`.
- [`site.webmanifest`](site.webmanifest): manifiesto para instalar la app.
- `favicon.ico`, `favicon.svg` y `favicon-16.png`, `-32.png` y `-48.png`: pestaña del navegador.
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` y `maskable-512.png`: pantalla de inicio.
- `meloxo-symbol-*.svg`: variantes del símbolo (un color, cuadrado e ícono de app).
