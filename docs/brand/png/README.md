# Exportaciones (PNG)

Archivos PNG con fondo transparente para documentos y diapositivas. En la app usa siempre los SVG de [`docs/brand/svg/`](../svg/README.md).

Las versiones horizontales miden 1200 px de ancho; las apiladas, 800 px, y el símbolo, 512 px. Algunos nombres llevan ese ancho al final, como `meloxo-stacked-black-800.png`. Las versiones `-color-dark` y `-white` necesitan fondo oscuro.
