MELOXO · 02-separacion · servicios separados
Desde la raíz de FLDSMDFR

Para levantar con contenedores
  - Docker Engine con el daemon activo y Docker Compose (comando docker compose),
    o Docker Desktop que incluye ambos. La cuenta debe poder ejecutar docker ps.
    Usa una versión que admita docker compose up --wait y perfiles de servicios.
  - Acceso a internet en la primera construcción para descargar imágenes, paquetes
    del sistema y dependencias de Python y Node. Docker instala Python y FFmpeg
    en la imagen de ejecución y usa Node durante la compilación de la interfaz.
  - Puertos disponibles: 8080 para la aplicación y 127.0.0.1:5433 para PostgreSQL.
  - Un navegador. Para los comandos de verificación también se utiliza curl.

Comprobación
  docker --version
  docker compose version
  docker ps

Configuración
  Si falta .env, copia .env.example a .env. Si ya existe, edítalo conservando
  los valores anteriores. Configura CATALOG_INTERNAL_TOKEN y tres contraseñas
  hexadecimales independientes: USERS_DB_PASSWORD, CATALOG_DB_PASSWORD y
  PLAYBACK_DB_PASSWORD.
  Genera cada secreto por separado. Una opción es openssl rand -hex 32.
  POSTGRES_PASSWORD y JWT_SECRET deben tener valor. Para pruebas locales usa
  también la contraseña correcta en DATABASE_URL. En un volumen existente,
  conserva POSTGRES_PASSWORD, el nombre del proyecto Compose y el JWT_SECRET.
  ADMIN_EMAIL y ADMIN_PASSWORD permiten crear el primer administrador.
  JAMENDO_CLIENT_ID habilita la importación y la semilla de Jamendo. Se puede
  comprobar la separación con una pista local subida por un compositor.

Si vienes del monolito o del incremento 1, sigue el corte con los escritores
detenidos y una copia de seguridad en docs/02-separacion.md antes de arrancar.

Arranque
  docker compose config --quiet
  docker compose up -d --build
  docker compose ps -a
  Abre http://localhost:8080. El contenedor migrate debe terminar con código 0.

Para ejecutar pytest directamente en el equipo (opcional)
  Python 3.11 o posterior, venv y pip; PostgreSQL del Compose en 5433.
  Desde backend:
    python3 -m venv .venv
    .venv/bin/pip install -e '.[dev]'
    .venv/bin/python -m pytest -q
  La suite crea y vacía la base de pruebas meloxo_test. Usa una instancia de
  PostgreSQL de desarrollo y mantén TEST_DATABASE_URL sin configurar.
